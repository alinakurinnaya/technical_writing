# Документация веб-cайта для записи на ивент

Папка содержит полный комплект документации для MVP веб-приложения, предназначенного для публикации информации о событиях и сбора заявок от участников.

Приложение разработано на SvelteKit с использованием базы данных SQLite и ORM Prisma. Документация описывает требования к продукту, сценарии использования, процесс администрирования и историю изменений.

## Структура документации

| Документ | Назначение | Целевая аудитория |
| :--- | :--- | :--- |
| **[Техническое задание](./Requirements_Specification.md)** | Описание бизнес-логики, ролей, модели данных и нефункциональных требований к MVP. | Разработчики, тестировщики, менеджеры продукта. |
| **[Руководство пользователя](./user_guide.md)** | Инструкция по просмотру страницы ивента, заполнению формы записи и обработке ошибок. | Посетители сайта (участники). |
| **[Руководство администратора](./admin-guide.md)** | Инструкция по входу в панель управления, работе со списком участников, смене статусов и экспорту данных. | Администраторы ивенторов. |
| **[История изменений (Changelog)](./Changelog.md)** | Список добавленных функций и исправленных ошибок. Ведется по стандартам Keep a Changelog и SemVer. | Разработчики, администраторы. |

## Технический стек проекта

Документация описывает приложение со следующей архитектурой:
*   **Frontend и Backend:** SvelteKit (TypeScript).
*   **База данных:** SQLite.
*   **Взаимодействие с БД:** Prisma ORM.
*   **Аутентификация:** Сессионные cookie (защита панели администратора).
