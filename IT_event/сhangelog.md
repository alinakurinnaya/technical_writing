## [0.4.0] - 2026-10-27

### Добавлено
- Первоначальный черновик «Руководства пользователя» и «Руководства администратора» (описание входа в систему, управления участниками, смены статусов и выгрузки CSV).
- Зафиксированы ограничения текущего MVP в документации (отсутствие интерфейса для создания/редактирования ивентов).

### Исправлено
- Исправлена проблема со сбросом данных в формах при доступе к сайту через внешние туннели (в `vite.config.ts` добавлены настройки `hmr` с использованием протокола `wss` и порта `443`).
- Настроен постоянный поддомен в сервисе Tuna для предотвращения обрыва сессии туннеля (ошибка 404 «Туннель не найден»).

## [0.3.0] - 2026-10-26

### Добавлено
- Добавление участников вручную через панель администратора (с валидацией обязательных полей и проверкой дублей).
- Экспорт списка участников в формат CSV.
- Обработка данных при экспорте: поддержка кириллицы (UTF-8 BOM), разделитель `;`, время в UTC с суффиксом `Z` и защита от CSV-инъекций.
- Кнопка «Экспорт CSV» в шапке админ-панели.

### Исправлено
- Исправлен баг с реактивностью Svelte 5 при обновлении таблицы участников после добавления новой записи (внедрены руны `$derived`).
- Исправлено поведение формы добавления участника (теперь при ошибке валидации форма не сбрасывается при нажатии Enter).

## [0.2.0] - 2026-10-25

### Добавлено
- Авторизация в админке (`/admin/login`) с проверкой пароля через `bcryptjs` и cookie-сессией.
- Защита маршрутов (`+layout.server.ts`) с редиректом на страницу логина.
- Дашборд администратора с таблицей всех участников ивента.
- Управление участниками: удаление (с подтверждением) и смена статуса посещения прямо в таблице.
- Навигация: ссылки перехода между публичной страницей, админкой и страницей логина.
- Тестовый администратор в скрипте `seed.ts` (логин: `admin`, пароль: `admin123`).

### Изменено
- В админке дата записи отображается в локальном формате браузера (`YYYY-MM-DD HH:mm`).
- Получение ивента в админке через `findFirst` (в MVP подразумевается один активный ивент).

### Исправлено
- Ошибка `500 Internal Server Error` при входе в админку (исправлен поиск ивента по `id`).
- Ошибка `405 Method Not Allowed` на публичной странице (корректный экспорт `actions` в серверном файле).
- Синтаксис обработчика `onchange` для выпадающего списка статусов (адаптация под Svelte 5).
- Предупреждение реактивности Svelte для переменной `formattedDate`.
- Предупреждения доступности (a11y) в форме авторизации (добавлена связка `id` и `for` в `<label>`).

## [0.1.0] - 2026-10-23

### Добавлено
- Первоначальная настройка проекта (SvelteKit, TypeScript, Tailwind CSS).
- Подключение базы данных SQLite и ORM Prisma.
- Создание схемы данных для сущностей: Event, Participant, Admin.
- Скрипт для генерации тестового ивента (seed).
- Публичная страница ивента (`/event/[id]`) с выводом названия, даты, места и описания.
- Форма записи на ивент с серверной валидацией (имя, email).
- Защита от дублей по email с выводом понятного сообщения об ошибке.

### Исправлено
- Конфликты путей при импорте Prisma Client и драйвера `better-sqlite3` в среде WSL.
