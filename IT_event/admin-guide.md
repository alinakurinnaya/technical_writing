# Руководство администратора

Это руководство описывает, как управлять ивентом и списком участников через панель администратора.

## 1. Вход в систему

Для доступа к панели администратора перейдите по адресу:
`http://localhost:5173/admin/login` (или ваш публичный домен).

Введите персональные учетные данные: **Логин** и **Пароль**

## 2. Управление ивентом (Event)

В текущей версии (MVP) создание и редактирование данных самого ивента (название, дата, место, описание) происходит на уровне базы данных. Интерфейс для этого запланирован в следующих версиях.

Чтобы изменить информацию об ивенте, разработчику необходимо отредактировать данные в скрипте `prisma/seed.ts` или напрямую в базе данных SQLite, после чего выполнить команду `npx prisma db seed`.

## 3. Управление участниками

После входа в систему вы попадаете на главную страницу панели администратора — дашборд участников. Здесь отображается таблица со всеми, кто записался на ивент.


### 3.1. Добавление участника вручную
Если кто-то хочет записаться на ивент по телефону или лично, вы можете добавить его вручную:
1. Нажмите кнопку **«+ Добавить»** в правом верхнем углу.
2. В появившейся форме заполните обязательные поля: **Имя** и **Email**. Поля «Телефон» и «Комментарий» необязательны.
3. Нажмите кнопку **«Сохранить»**. 
4. Если участник с таким email уже существует, появится сообщение об ошибке. После успешного добавления форма закроется, а участник появится в таблице.


### 3.2. Редактирование данных участника
Вы можете изменить статус посещения участника прямо в таблице:
1. Найдите нужного участника в списке.
2. В колонке **«Статус»** выберите один из вариантов из выпадающего списка:
   *   **Ожидает** (по умолчанию)
   *   **Пришел**
   *   **Не пришел**
3. Изменения сохраняются автоматически.

*Изменение имени, email, телефона или комментария участника в текущей версии не предусмотрено.*

### 3.3. Удаление участника
Если запись была создана по ошибке, вы можете её удалить:
1. Напротив имени участника в колонке **«Действия»** нажмите на  **«Удалить»**.
2. В появившемся окне подтвердите удаление, нажав **«ОК»**. Участник будет безвозвратно удален из базы данных.

## 4. Экспорт данных (CSV)

Для работы с данными вне сайта (например, для печати списков или отчетов) предусмотрен экспорт.

1. В правом верхнем углу нажмите зеленую кнопку **«Экспорт CSV»**.
2. Браузер автоматически скачает файл с именем формата `event_participants_YYYY-MM-DD.csv`.

**Особенность файла:** Время записи участников указано в формате UTC (с суффиксом `Z`).
