# DevSecOps Glossary

Краткий справочник терминов по DevSecOps: от базовых принципов до практик защиты инфраструктуры.

## Зачем этот проект

В DevSecOps много аббревиатур и пересекающихся понятий: SAST, DAST, SCA, SBOM, CVE, CVSS. Этот справочник помогает быстро разобраться в терминологии и увидеть, как понятия связаны между собой.

**Аудитория:** начинающие разработчики и инженеры по безопасности, технические писатели, студенты.

## Структура

- [01. Методология и культура](01-methodology.md) — DevSecOps, Shift Left, Zero Trust, Shared Responsibility
- [02. Безопасность приложений (AppSec)](02-appsec.md) — SAST, DAST, IAST, SCA, Secrets Detection
- [03. Управление уязвимостями](03-vulnerability-mgmt.md) — CVE, CVSS, CWE, SBOM, Триаж
- [04. Инфраструктура](04-infrastructure.md) — IaC, CaC, Container Scanning, Kubernetes Security, Secrets Management, Monitoring & Logging

## Как пользоваться

1. Выберите нужный раздел в списке выше.
2. В начале каждого файла есть список терминов со ссылками.
3. Каждый термин описан по единому шаблону: определение, почему это важно, пример, связанные термины, источники.

## Что демонстрирует проект

- **Docs-as-code:** документация хранится в Git, написана в Markdown.
- **Структурирование:** термины сгруппированы по категориям, внутри - единый формат.
- **Навигация:** перекрёстные ссылки между терминами и разделами.
- **Работа с источниками:** каждый термин опирается на авторитетные источники (NIST, OWASP, CNCF).

## Источники

- OWASP DevSecOps Guideline
- NIST SP 800-218 (SSDF)
- CNCF Security Whitepaper
- Документация облачных провайдеров (AWS, Yandex Cloud, VK Cloud)
