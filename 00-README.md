<h1 id="devsecops-glossary">DevSecOps Glossary</h1>
<p>Краткий справочник терминов по DevSecOps: от базовых принципов до практик защиты инфраструктуры.</p>
<h2 id="зачем-этот-проект">Зачем этот проект</h2>
<p>В DevSecOps много аббревиатур и пересекающихся понятий: SAST, DAST, SCA, SBOM, CVE, CVSS. Этот справочник помогает быстро разобраться в терминологии и увидеть, как понятия связаны между собой.</p>
<p><strong>Аудитория:</strong> начинающие разработчики и инженеры по безопасности, технические писатели, студенты.</p>
<h2 id="структура">Структура</h2>
<ul>
<li><a href="01-methodology.md">01. Методология и культура</a> — DevSecOps, Shift Left, Zero Trust, Shared Responsibility</li>
<li><a href="02-appsec.md">02. Безопасность приложений (AppSec)</a> — SAST, DAST, IAST, SCA, Secrets Detection</li>
<li><a href="03-vulnerability-mgmt.md">03. Управление уязвимостями</a> — CVE, CVSS, CWE, SBOM, Триаж</li>
<li><a href="04-infrastructure.md">04. Инфраструктура</a> — IaC, CaC, Container Scanning, Kubernetes Security, Secrets Management, Monitoring &amp; Logging</li>
</ul>
<h2 id="как-пользоваться">Как пользоваться</h2>
<ol>
<li>Выберите нужный раздел в списке выше.</li>
<li>В начале каждого файла есть список терминов со ссылками.</li>
<li>Каждый термин описан по единому шаблону: определение, почему это важно, пример, связанные термины, источники.</li>
</ol>
<h2 id="что-демонстрирует-проект">Что демонстрирует проект</h2>
<ul>
<li><strong>Docs-as-code:</strong> документация хранится в Git, написана в Markdown.</li>
<li><strong>Структурирование:</strong> термины сгруппированы по категориям, внутри - единый формат.</li>
<li><strong>Навигация:</strong> перекрёстные ссылки между терминами и разделами.</li>
<li><strong>Работа с источниками:</strong> каждый термин опирается на авторитетные источники (NIST, OWASP, CNCF).</li>
</ul>
